## Findings

1. **BLOCKING -- a null principal is accepted silently, giving a tenant with zero principals.** `internal/config/decode.go:528-553`: for `principals: [{email: ~}]` (or `- email:` with the value left blank) `emailPresent` is true, so the exactly-one check passes, but `f.str("email", false)` returns not-ok without a problem, and the `default: continue` at 551 drops the entry with no message. `Parse`/`Load` succeed and `config check` prints `config ok` for a tenant nobody can map to. This is the "null where a value is required" case, and it breaks the invariant `FuzzParse` asserts (`len(tn.Principals) == 0`). Fix: in the `default` branch report `<p>.email: is required` (or `.common_name`) when the present key is null, and after the loop report `principals: must not be empty` when `out` is empty and nothing was reported. Add both as rule cases.

2. **BLOCKING -- `Decide` and `Permits` fail open on zero and undefined values.** `internal/policy/policy.go:185-194`: a zero-value `Tool{}` (`Requires: AccessNone`, `InputNone`) is allowed on every server of the tenant, including one granting `AccessNone` (`Permits(none, none)` is true). `internal/policy/policy.go:140-152`: `NewEngine` accepts a tenant with an empty id, after which the zero `Principal{}` and zero `Server{}` match each other, so all-zero inputs give Allow. `internal/tenant/tenant.go:124` with `tenant_test.go:83-87`: a grant outside the defined range (`AccessLevel(9)`) permits `full`, and the test pins that. Fix: `Permits` returns false when either level is above `AccessFull`; `Decide` denies with `access_denied` when the required level is `AccessNone` (a tool must declare at least `look`) and with `not_found` when `p.Tenant == ""`; `NewEngine` rejects an empty tenant id. Add the zero-value cases to `TestDecide` and invert the tenant test.

3. **ADVISORY -- built-in command rules wrongly deny common read-only commands** (`internal/policy/commands.go`). (a) `|` and `(` inside a quoted pattern count as command starts (line 24): `grep -E 'sshd|sudo' /var/log/auth.log`, `last -x | grep -E '(reboot|shutdown)'`. (b) `pipe-to-shell` (lines 40, 92) denies `curl -s http://127.0.0.1:8080/health | python3 -m json.tool` and `| perl -pe ...`: for interpreters, match only when no script or module argument follows. (c) `command` is a wrapper (line 29), so `command -v sudo` is denied. (d) `fork-bomb` (line 100) matches `f() { dmesg | tail && echo ok; }` because `&&` satisfies `&`. Add each as a must-not-match case, or name it in the 5.3 callout.

4. **ADVISORY -- bypasses a guard rail could reasonably catch** (same file). Slip past `sudo` (and every `cmd()` rule): `eval sudo id`, `\sudo id`, `"sudo" id`, `env -u HOME sudo id` and `timeout -s KILL 5 sudo id` (an option that takes a value), `find . -exec sudo id \;`. Others: `curl x |& sh`, `curl x | csh`, `curl x | env A=1 bash`, `rm -rf "/"`, `dd if=a of="/dev/sda"`. Cheap wins: add `eval` to the wrappers, allow an optional leading backslash or quote before the word, add `-exec`/`-execdir` as a command start. Correctly caught already: env assignments, `env`/`exec`/`nohup`/`time`/`xargs`, absolute paths, `$(...)`, backticks, subshells, newlines and here-doc bodies, separators without spaces. Not worth chasing (D6): variables, encodings, `echo ... | sh`, here-strings, `ssh host ...`.

5. **ADVISORY -- path globs cannot express a subtree** (`internal/policy/paths.go:17-29`). `path.Match` `*` stops at a slash, so `/proc/self/root/etc/shadow` and `/proc/<pid>/cwd/...` pass (an always-present link, not an operator's symlink), `/root/.config/gcloud/legacy_credentials/x/adc.json` passes, and an operator cannot deny a tree. Add a trailing `/**` prefix form, then `/proc/*/root/**` and `/proc/*/cwd/**`. Also missing from the names list: `privkey*.pem`, `.docker/config.json`, non-default SSH key names.

6. **ADVISORY -- audit.** `internal/audit/audit.go:66-86`: the logger stops after a failed write because of a possible partial line, but the next `Open` appends straight onto that partial line; on open, terminate an unterminated last line first. `audit.go:110`: `json.Marshal` escapes `&`, `<`, `>`, so each `&` of `a && b` is stored as a six-character unicode escape and the command cannot be grepped; use an encoder with `SetEscapeHTML(false)`. `Write(Event{})` writes an event with an empty name; refuse it.

7. **ADVISORY -- `strings.EqualFold` on emails** (`internal/tenant/tenant.go:189`) uses Unicode simple folding, so U+017F and U+212A fold to `s` and `k`. Compare ASCII-lowercased strings and refuse a non-ASCII subject.

8. **ADVISORY -- root-level problems have an empty path** (`internal/config/decode.go:347`): a list or string at the root prints `: expected a mapping, ...`. Pass `config`; the tests at `config_test.go:411-412` only match the message.

9. **ADVISORY -- `internal/deprule` enforces less than section 4 says** (`deprule_test.go:19-24`): four packages, top directory only, and nothing checks module-wide that `internal/testkit` is imported only from `_test.go` files. Add that one walk over `cmd/` and `internal/`.

10. **ADVISORY -- `max_upload_bytes` maximum** (`internal/config/limits.go:46`): 1572864 bytes is exactly 2 MiB once base64-encoded, so with the JSON envelope it can never fit the 5.8 body cap. Lower it and correct the callout row.
